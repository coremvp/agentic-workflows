# Project judgment

This package ships no observed project lessons. Starter branding,
another founder's preferences and simulated feedback are not evidence for this
project. Load this support only for a relevant consequential choice or real
feedback retention.

Lead may retain a transferable lesson from authorized work using
[the feedback method](studies.md#learn-from-actual-response). Keep each entry
self-contained: context/when useful; preference, observation or hypothesis;
recoverable source and non-identifying observation; decision it informs;
scope/exception; what would revise it. Link binding medium rules to their owner.

Search entries by the current audience, artifact and decision. Report no pertinent
lesson when none exists. Current human direction, product truth and applicable
domain contracts outrank historical learning. This file grows from genuine
response and can shrink when evidence changes; it is not a permanent house style.
