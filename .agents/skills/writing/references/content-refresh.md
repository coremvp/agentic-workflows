# Content refresh

Load when an existing artifact has dated truth, changing intent, incomplete
coverage or a useful but weak answer. Inspect its source owner before rewriting.

## Choose keep, refresh or rewrite

Inventory current reader job, canonical URL/anchors, useful passages, source
claims, actual behavior and available search/customer evidence. Keep an accurate
useful artifact without cosmetic churn. Refresh when the job holds but facts,
proof or a bounded section need repair. Rewrite when the argument/job is wrong;
explain why and preserve valuable material where possible.

A fictional invite guide missing the supported resend step needs that recovery
added and stale instructions corrected, not a duplicate “invites v2” page. A
page promising a feature still behind a disabled flag needs truth correction;
changing copy cannot make the feature available.

## Protect the reader's route

Preserve useful URL, anchors, links, commands and voice unless the actual owner
has a justified change. SEO owns intent/canonical/redirect decisions. Check
inbound references when moving a section and give a bounded handoff if redirect
or metadata code is needed. Date updates reflect substantial relevant work, not
pretend freshness.

Revise source-dependent behavior, availability/eligibility, examples and recovery.
Remove obsolete instructions and unsupported claims; retain limitations still
true. Distinguish a current-source correction from a hypothesis about low traffic.
Do not “refresh” technical details from memory when installed APIs matter.

## Verify the changed promise

Code runs the applicable literal-guide/content/link/metadata checks under authority;
Review reads the source and evidence. A local render verifies presentation, not
provider outcomes. Compare the revised artifact to the original useful answer:
what is clearer, what truth changed, what stayed and what remains unverified?

Deliver the maintained artifact, significant corrections, canonical/dependency
handoffs and actual limits. No new page/calendar or guaranteed ranking lift is
implied. [Editing](editing.md) owns expression; Marketing only reopens the argument
when the audience/business decision materially changed.
