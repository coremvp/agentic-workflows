# Short-form video

Load for a short-video script, storyboard or authorized production. Separate
writing, captured material, proposed capture, playback and audience evidence.

## Build beats around visible proof

Name the viewer's task/question and central supported change. Select an opening
that makes the situation recognizable, a mechanism/proof beat, the consequence
and useful finish. A hook should be fulfilled, not held hostage to watch time.
A fixed first-second formula or guaranteed retention threshold is not a method.

For a fictional validation-recovery clip, show the mistaken input, real error,
retained safe fields and correction. If only the error was captured, list recovery
capture as missing; don't write as if the full result was filmed. A reconstruction
or seeded account must stay labeled.

## Write production-useful instructions

A compact beat table can contain words/caption, visible action, source/asset,
intended duration and missing capture. Keep on-screen language readable at the
actual view, distinguish labels from speech, and leave room for captions and
interface context. Sound-off understanding may matter; narration and audio rights
still need deliberate decisions. Don't promise lip sync, sound quality or easing
without inspected production.

Timing is a provisional estimate until actual reading/edit/playback. Trim repeated
ideas before accelerating speech or making text tiny. Use current
[media constraints](../../marketing/references/social-media-specs.md) for the
requested platform/format; unavailable assets/tools stay explicit.

## Deliver the requested level of completion

A script/storyboard is a plan, a still is composition, a rendered video is media,
and inspected playback establishes timing/cuts within its scope. Code runs
production and checks; Taste helps sequence/voice and meaningful comparison.
Audience effectiveness needs actual contextual response, not model enthusiasm.

Return the script/asset, truthful capture map, intended timing and next missing
production step. No publishing/account/vendor/spending or application change is
authorized merely by loading this reference.
