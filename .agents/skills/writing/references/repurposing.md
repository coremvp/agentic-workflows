# Repurposing

Load when a supported source artifact must become a different requested form.
Marketing's [content promotion](../../marketing/references/content-promotion.md)
owns encounter jobs; Writing owns how the argument changes medium.

## Select the transferable idea

Read the source, intended reader/encounter and requested output. Extract central
claim, inspectable proof, limitation, memorable mechanism and useful next action.
Select what the new format can carry. A short post shouldn't compress every
section into a feature list; a carousel can show a meaningful sequence; a video
needs visible/audible beats and available capture.

Keep a small source-to-expression map for consequential claims. Preserve numbers,
eligibility, timing, confidence and actual evidence scope. A hypothetical example
stays hypothetical. Do not turn a local fixture demonstration into a customer
success story or a proposed integration into an available feature.

Example: an article about version-bound review can become one post showing the
misunderstanding and mechanism. Its claim isn't “no more revision mistakes.”
A guide's exact recovery step can remain linked rather than squeezed into a
misleading summary.

## Rebuild for the medium

Use [social posts](social-posts.md), [carousels](carousels.md) or
[short-form video](short-form-video.md) only for the selected artifact. Reorder
around the encounter; reuse strong wording where it still fits. Don't imitate
a different creator's voice or produce an automatic all-platform bundle.

Verify that the adapted promise is delivered, key limitations remain visible
and added examples are original/labeled. Taste helps consequential composition;
Code produces/checks actual media; no application UI agreement ceremony is needed
unless an application interface is actually changed.

Deliver the requested asset/draft, relevant source binding and missing capture/
production limits. Drafts are not published; scripts are not playback proof.
Response remains pending until real people encounter the actual artifact.
