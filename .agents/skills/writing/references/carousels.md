# Carousels

Load when a sequence of visible panels helps the reader understand an argument.
Writing owns words/sequence; Taste informs consequential composition; Code
produces and checks authorized media. Frontend's visual agreement applies only
when changing an application interface, not ordinary social assets.

## Choose a sequence for the argument

A comparison can alternate prior/current behavior; a process can show decisions
and result; an explanation can reveal a mechanism; a misconception can show
claim/evidence/correction. Choose the relationship that deserves pictures, not
a fixed slide count or every platform's fashionable pattern.

Sketch each panel's job: promise, distinct idea/proof, transition and finish.
Opening promises must match coverage. “Three recovery mistakes” needs three
actual distinct mistakes, not a conclusion mislabeled as the third. If the
source supports only two, change the promise instead of inventing one.

For a fictional version review sequence, show the revision confusion, binding
mechanism and supported recovery. A large decorative headline repeating the same
claim on each panel contributes little. Evidence may need more room than a
slogan; resize/restructure rather than force unreadable text.

## Make the visible hierarchy intentional

Use a stable alignment/grid, readable type at actual viewing size, sufficient
contrast and consistent semantic roles. Let emphasis follow the argument. Keep
captions and labels useful, not redundant. Distinguish reference pictures,
current product and proposed artwork. Adapt a studied relationship rather than
copy protected pixels or another brand's surface.

Where actual media production is requested, Code renders applicable previews,
checks crop/readability and promised sequence integrity. A text outline does not
prove the rendered artifact. Motion/audio need their own playback evidence.

Deliver panel argument/words or produced media as requested, source/proof limits
and useful next action. No automatic application redesign, publication or broad
campaign. [Repurposing](repurposing.md) preserves source truth; human judgment
calibrates creative quality without a universal slide score.
