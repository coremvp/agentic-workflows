# International SEO

Load when locale URLs, hreflang, canonicals, sitemap or translated answer quality
matter. Inspect the host's actual origin/locale/routing owner and installed
framework; don't propose a parallel URL system from a generic example.

## Make the locale graph coherent

List actual localized URLs, language/region intent, availability, canonical,
hreflang relationships, fallback and sitemap membership. Locale variants should
help real readers, not be thin automatic pages for every market.

[Google's localized-version guidance](https://developers.google.com/search/docs/specialty/international/localized-versions)
describes reciprocal alternate references including the page itself, fully
qualified URLs and `x-default` for an appropriate fallback. Choose a supported
annotation method; verify language/region codes and actual targets. Canonical
and alternate relationships must express the intended owners consistently.
Checked 14 October 2026; recheck when implementing a source-dependent change.

## Diagnose the actual contradiction

| Conflict | Useful investigation |
| --- | --- |
| One locale names an alternate that doesn't refer back | Compare generated relationships and actual URLs |
| Locale canonical points to an unrelated/default answer | Inspect canonical intent and content equivalence |
| Sitemap advertises missing/private locale | Check availability/access and inventory owner |
| Wrong-origin alternates | Reuse actual host configuration |
| Auto redirect prevents a reader/crawler reaching a version | Inspect routing and explicit locale choice |
| Translation repeats text without serving the locale | Product/Writing quality and audience decision |

For a fictional French guide canonicalized to the English page while the sitemap
advertises French as the answer, inspect why before changing everything. Recommend
a bounded coherent correction and framework owner; don't blindly copy English
metadata or promise a ranking increase from annotations.

Code runs actual route/metadata checks with relevant rejects under authority.
Review reads source/evidence. Explain which graph relationships were proved,
which remain unrun and whether evidence was fixture, source or live. Translation,
market expansion, provider installs and publication remain distinct decisions.
