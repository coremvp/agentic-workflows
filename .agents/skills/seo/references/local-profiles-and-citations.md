# Local profiles and citations

Load for business-profile eligibility, fields, privacy, duplicates or third-party
listings. Inspect actual business model and the current provider's official rules.

[Google Business Profile guidelines](https://support.google.com/business/answer/3038177)
require accurate representation and distinguish eligible in-person/service-area
businesses from online-only activity. Service-area/address handling has specific
conditions. Use real operating facts and current guidance, not a fabricated
storefront, virtual office or keyword-stuffed identity. Checked 14 October 2026.

## Make field decisions from truth

| Field/issue | Decision evidence |
| --- | --- |
| Name/category | Real business identity and actual primary service |
| Address/service area | Where customers are served and applicable display/privacy rules |
| Hours/contact | Actual availability and supported contact path |
| Website/action link | Relevant public owner and correct destination |
| Duplicate profile | Same business versus distinct legitimate location, provider policy |
| Citation inconsistency | Actual identity versus outdated/incorrect third-party record |
| Reviews | Genuine response with permissions; never invented or purchased proof |

Audit existing records before recommending new ones. A directory mismatch may
need correction, not a second listing. Keep exact source/date and known access
limitations. Avoid exporting personal addresses or account data into public
reports. Verification/ownership doesn't authorize arbitrary edits.

Recommend a bounded field/listing correction with evidence and applicable rule,
or explain ineligibility. When business facts are missing and change the result,
ask one material decision through Lead. Don't guess an address to complete a form.
Account access, edits, verification, outreach and publication need explicit
authority; Code owns authorized checks and operations.

Link a useful local page only when it actually serves the reader; don't route
every location to a generic conversion page. Use
[local pages and measurement](local-pages-and-measurement.md) for that decision.
